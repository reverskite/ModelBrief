# ModelBrief MVP 기획서

## 1. 프로젝트 한 줄 소개

**ModelBrief**는 AI 실험 결과를 등록·비교하고, LLM이 등록된 수치와 파일 근거를 바탕으로 분석 요약 및 보고서 초안을 생성하는 개인 프로젝트입니다.

## 2. 문제 정의

모델 실험을 반복할수록 데이터셋, 학습 조건, 성능 지표, 결과 이미지가 흩어집니다. 실험 간 차이를 다시 확인하고 보고서로 정리하는 과정도 반복됩니다.

ModelBrief는 이 정보를 한곳에 모으고, **실제 등록된 데이터만 근거로** 실험 결과를 비교·설명하도록 돕습니다.

## 3. 목표와 범위

### MVP 목표

- 실험 결과를 CSV로 등록하고 조회한다.
- 여러 실험을 선택해 성능을 표와 그래프로 비교한다.
- LLM이 선택된 실험 데이터만 사용해 비교 분석과 보고서 초안을 작성한다.
- 답변에 실험명, 지표, 수치로 된 근거를 표시한다.

### MVP에서 제외

- 실제 모델 학습 실행 및 GPU 관리
- 의료 진단·치료 권고
- PDF, 이미지 OCR, 복잡한 벡터 검색
- 다중 조직·기업용 권한 체계

## 4. 핵심 사용자 흐름

1. 사용자가 로그인한다.
2. 프로젝트를 만들고 CSV 파일을 등록한다.
3. 등록된 실험 목록에서 비교할 실험을 선택한다.
4. 지표 표와 그래프로 차이를 확인한다.
5. `분석 요청` 또는 `보고서 초안 생성`을 실행한다.
6. LLM 답변과 함께 사용한 실험명·지표·수치를 확인한다.

## 5. 초기 데이터

첫 데모는 LUNG-CDSS의 CT 종양 분할 실험 기록을 사용한다.

| 실험 | Dataset | Crop | Epochs | 검증 수 | Dice | Checkpoint |
|---|---:|---:|---:|---:|---:|---|
| Dataset503 | 503 | - | 100 | 84 | 0.4202 | final |
| Dataset504_100 | 504 | 50mm | 100 | 84 | 0.4557 | final |
| Dataset504_250 | 504 | 50mm | 250 | 84 | 0.5085 | final |
| Dataset504_250_best | 504 | 50mm | 250 | 84 | 0.5124 | best |

> Dice는 분할 영역의 겹침 지표이며, 임상 진단 정확도나 병기 분류 정확도를 의미하지 않는다.

## 6. 화면 구성

### A. 로그인

- 이메일·비밀번호 로그인
- 개인 프로젝트로 단일 사용자 기준부터 구현

### B. 프로젝트·실험 목록

- 프로젝트 생성
- CSV 업로드
- 실험 카드: 실험명, 데이터셋, 최종 지표, 생성일

### C. 비교 대시보드

- 실험 2개 이상 선택
- 지표 비교 표
- Dice 또는 AUC 막대그래프
- 조건 차이: 데이터셋, crop, epochs, checkpoint

### D. LLM 분석 패널

- 질문 예시: `Dataset503과 Dataset504_250_best의 차이를 분석해줘.`
- 답변 규칙: 제공된 실험 데이터 이외의 사실을 단정하지 않음
- 근거 카드: 실험명 / 지표 / 수치

### E. 보고서 초안

- 목적
- 비교 조건
- 핵심 결과
- 해석과 한계
- 사용 근거

## 7. 권장 기술 구성

| 영역 | MVP 선택 |
|---|---|
| Frontend | Next.js + TypeScript + Tailwind CSS |
| Backend | Django REST Framework |
| Database | PostgreSQL |
| LLM 연동 | OpenAI API 또는 동등한 LLM API |
| 차트 | Recharts |
| 인증 | JWT |
| 배포 | Docker Compose 기반 배포 |
| 테스트 | Django API 테스트 + 핵심 화면 테스트 |

## 8. 데이터·LLM 설계 원칙

- 성능 계산과 비교 값은 서버 코드가 처리한다.
- LLM에는 선택된 실험의 구조화된 데이터만 전달한다.
- LLM은 의학적 판단, 성능 과장, 근거 없는 원인 단정을 하지 않는다.
- 응답에는 최소 두 개 이상의 근거 항목을 포함한다.
- 원본 CSV와 업로드 시각을 보존한다.
